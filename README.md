# 😎 Jogo de Adivinhação em Ruby

Projeto desenvolvido como atividade prática da **Rocketseat**, com o objetivo de aplicar os conceitos básicos da linguagem **Ruby** e reforçar a lógica de programação.

O jogo consiste em o programa gerar um número secreto dentro de um intervalo definido pelo usuário, e o jogador deve tentar adivinhar esse número com base nas dicas fornecidas pelo sistema.

---

## 🚀 Funcionalidades

- Definição de um intervalo mínimo e máximo pelo usuário
- Geração de um número aleatório dentro do intervalo
- Comparação do palpite com o número secreto
- Feedback ao usuário:
  - **"Mais alto"** quando o palpite é menor
  - **"Mais baixo"** quando o palpite é maior
  - **"Você acertou!"** quando o número é descoberto
- Laço de repetição até o acerto

---

## 🧠 Conceitos praticados

- Entrada e saída de dados (`gets` e `puts`)
- Tipos de dados (`Integer`)
- Geração de números aleatórios (`rand`)
- Estruturas condicionais (`if / elsif / else`)
- Estruturas de repetição (`while`)
- Lógica de programação
